# Полное руководство по Telegram CRM-боту

Это руководство предназначено для клиентов, мастеров, администраторов и владельца бизнеса.
Оно описывает фактические функции текущей версии бота и объясняет простыми словами, что делает
каждая кнопка.

Если полный справочник пока не нужен, начните с подходящей короткой инструкции:

- [«Запуск за 15 минут»](QUICK_START_15_MIN.md) — для владельца бизнеса;
- [«Ежедневная работа мастера»](MASTER_DAILY_GUIDE.md) — для мастера;
- [«Клиентская часть»](CLIENT_GUIDE.md) — для посетителя салона.

Установка на сервер, сбор данных у покупателя и техническая передача вынесены в отдельный
[регламент установки экземпляра](DEPLOYMENT_FOR_CLIENT.md). Этот документ остаётся именно
пользовательским справочником.

> Внешний вид меню зависит от роли сотрудника и включённых функций. Если раздел отключён
> владельцем, кнопка исчезает из клиентского меню. Старая кнопка из сохранённой Telegram-клавиатуры
> безопасно обновит меню и не запустит отключённую функцию.

## 1. Роли и способы входа

| Роль | Что доступно |
|---|---|
| Клиент | Запись, просмотр услуг и мастеров, свои записи, отзывы, лист ожидания, уведомления, контакты и приватность |
| Мастер | Только свои окна, записи, предоплаты и портфолио |
| Администратор (`MANAGER`) | Записи всех мастеров, окна, услуги, клиенты, предоплаты, рассылки и статистика |
| Менеджер записи (`RECEPTIONIST`) | Записи, клиенты и просмотр предоплат без опасных настроек бизнеса |
| Владелец (`OWNER`) | Все функции, сотрудники, настройки бизнеса, функции бота и запросы на удаление данных |

Права проверяются по базе данных при каждом действии. Одного Telegram ID в `.env` недостаточно
для постоянного доступа: `ADMIN_TELEGRAM_IDS` используется только для первичного создания
владельца.

### Команды

| Команда | Назначение |
|---|---|
| `/start` | Клиенту показывает приветствие и главное меню; сотруднику предлагает выбрать рабочий или клиентский режим |
| `/admin` | Открывает доступную текущей роли административную панель |
| `/master` | Открывает личную панель мастера |
| `/staff` | Открывает управление сотрудниками, если есть соответствующие права |
| `/whoami` | Показывает числовой Telegram ID текущего пользователя |
| `/delete_my_data` | Создаёт клиентский запрос на удаление персональных данных |

Кнопка «Отмена» в административной форме прекращает текущий ввод и возвращает основное меню.

## 2. Рекомендуемая первоначальная настройка

Владельцу лучше выполнять настройку в следующем порядке:

1. Открыть `/admin` → «🏢 Настройки бизнеса».
2. Заполнить название, приветствие, описание, телефон, адрес, карту и часовой пояс.
3. Добавить политику конфиденциальности и оферту.
4. Добавить источники клиентской поддержки.
5. Открыть «🛠 Услуги» и создать каталог.
6. Открыть «🪑 Рабочие места», создать реальные столы/кабинеты и назначить им услуги.
7. Открыть «👩‍💼 Мастера и сотрудники», настроить владельца как принимающего специалиста или
   пригласить мастеров, затем назначить каждому услуги.
8. Открыть «🧩 Функции бота» и оставить включёнными только нужные разделы.
9. При необходимости настроить «💳 Предоплаты».
10. Открыть «⚙️ Настройки» и проверить дедлайны, лимиты и напоминания.
11. Нажать «🔄 Синхронизировать профиль бота».
12. Создать тестовое окно и полностью пройти запись с отдельного клиентского аккаунта.

Если владелец работает один, создавать отдельного сотрудника не требуется. В своей карточке
сотрудника он включает «Принимать записи», назначает услуги и работает одновременно как владелец
и мастер.

## 3. Клиентский режим

### Первое открытие и согласия

При первом `/start` бот показывает опубликованное приветствие и ссылку на политику
конфиденциальности. Кнопка «✅ Подтверждаю согласие» сохраняет версию принятой политики.

После этого бот отдельно спрашивает согласие на рекламные сообщения:

- «Да, хочу получать новости» разрешает маркетинговые рассылки;
- «Нет, только сервисные сообщения» запрещает рекламу, но не отключает сообщения о записи,
  оплате, переносе или отмене.

### Главное клиентское меню

| Кнопка | Что делает |
|---|---|
| «✨ Записаться» | Запускает пошаговое оформление записи |
| «📅 Мои записи» | Показывает собственные записи клиента по страницам |
| «💵 Услуги и цены» | Открывает одну перелистываемую карточку услуги |
| «👩‍💼 Мастера» | Показывает карточки доступных мастеров по одной |
| «🖼 Портфолио» | Показывает опубликованные работы внутри бота или открывает настроенную внешнюю ссылку |
| «⭐ Отзывы» | Показывает опубликованные отзывы и позволяет оставить отзыв после визита |
| «⏳ Лист ожидания» | Создаёт и показывает запросы на освободившееся время |
| «🔔 Настройки уведомлений» | Управляет рекламой и напоминаниями о повторной записи |
| «🔁 Повторить запись» | Предлагает повторить подходящую прошлую услугу |
| «🛟 Поддержка и контакты» | Показывает телефон, адрес, карту и до пяти каналов связи салона |
| «🔐 Приватность» | Открывает политику, оферту и подсказывает команду удаления данных |

### «✨ Записаться»: полный сценарий

1. **Выбор услуги.** Бот показывает одну карточку, а стрелки переключают услуги. «Записаться»
   выбирает текущую услугу. Если у услуги есть фотография, она показывается сразу в этой карточке.
2. **Дополнительные услуги.** Можно отметить несколько дополнений. Кнопка «Продолжить» сохраняет
   выбор. Архивные и отключённые дополнения не используются.
3. **Выбор мастера.** Если выбор мастера включён и специалистов несколько, можно выбрать человека
   или «✨ Любой мастер». При одном специалисте шаг пропускается.
4. **Выбор даты.** Используется календарь; доступны только даты, для которых есть подходящие окна.
5. **Выбор времени.** Показываются только открытые окна, куда помещается длительность услуги и
   где доступно совместимое рабочее место. Рядом со временем указывается мастер.
6. **Имя.** Клиент вводит имя, которое увидит салон.
7. **Телефон.** Номер можно отправить кнопкой «📱 Отправить мой номер» или ввести вручную.
8. **Комментарий.** Можно написать пожелание или нажать «Без комментария».
9. **Фото-референсы.** Если функция включена, клиент загружает фотографии по одной, завершает
   кнопкой «✅ Готово» или выбирает «Без фотографий».
10. **Проверка.** Бот показывает услугу, мастера, дату, время, длительность, дополнения, стоимость,
    адрес и предоплату. «✅ Подтвердить» создаёт запись, «✏️ Изменить» возвращает к выбору.

Окно мастера не привязано к одной услуге заранее. Совместимость мастера, услуги, длительности и
рабочего места повторно проверяется в момент подтверждения. Это защищает от одновременной записи
двух клиентов на один физический стол.

Если цена услуги равна `0`, клиент видит «договорная». Такая цена обсуждается с мастером;
фиксированная предоплата для неё автоматически отключается.

### Оплата после записи

Возможны три режима:

- **Без предоплаты.** Запись сразу подтверждается.
- **Ручная предоплата.** Бот показывает безопасную инструкцию, сумму и срок резерва. «✅ Я оплатил»
  сообщает салону об оплате, «📎 Прикрепить чек» позволяет отправить фото или документ.
- **YooKassa.** «💳 Перейти к оплате» открывает защищённую страницу провайдера. Итоговый статус
  подтверждается сервером, а не только сообщением браузера.

«📍 Открыть на карте» использует ссылку из настроек бизнеса. «💬 Написать мастеру» использует
первый опубликованный контакт именно выбранного мастера.

Не отправляйте боту номер банковской карты, CVV/CVC, SMS-коды или срок действия карты.

### «📅 Мои записи»

Список разбит на страницы. Нажатие на запись открывает её карточку.

| Кнопка в карточке | Что делает |
|---|---|
| «🔄 Перенести» | Показывает только совместимые открытые окна; доступность зависит от дедлайна переноса |
| «❌ Отменить» | Отменяет запись после отдельного подтверждения; доступность зависит от дедлайна отмены |
| «🖼 Референсы» | Показывает прикреплённые фотографии |
| «➕ Добавить референс» | Добавляет фото до установленного лимита и дедлайна |
| «🗑 Удалить референсы» | Удаляет все референсы после подтверждения |
| «💬 Написать мастеру» | Открывает первый контакт выбранного мастера |
| «📍 Открыть на карте» | Открывает сохранённую для записи ссылку на карту |
| «⬅️ К списку» | Возвращает к собственным записям |

Адрес, карта, мастер, цена, длительность и название услуги сохраняются в снимке записи. Поэтому
позднейшее изменение каталога не переписывает историю уже созданной записи.

### «💵 Услуги и цены»

Услуги не отправляются десятками сообщений. В чате остаётся одна карточка со стрелками:

- «Записаться» начинает обычную запись с текущей услуги;
- фотография услуги, если она добавлена, показывается сразу вместе с текущей карточкой;
- стрелки переключают услуги;
- «Отменить оформление» прекращает сценарий.

### «👩‍💼 Мастера»

Карточка содержит имя, специализацию, описание и контакты мастера. Доступны:

- «✨ Записаться» — запускает общий безопасный сценарий записи;
- «🖼 Посмотреть фотографию» — показывает фото мастера;
- кнопки Telegram, WhatsApp, VK или других HTTPS-контактов;
- стрелки для перехода между мастерами.

### «🖼 Портфолио»

При встроенном режиме сначала выбирается мастер, затем показываются его опубликованные работы.
Можно листать работы, фильтровать по тегам, записаться, поделиться работой или вернуться в главное
меню. При режиме «Внешняя ссылка» бот открывает заданный владельцем сайт. При режиме «Выключено»
кнопка исчезает у клиента, но управление портфолио остаётся доступно владельцу.

### «⭐ Отзывы»

Опубликованные отзывы показываются по одному со стрелками. «Оставить отзыв» запускает форму:

1. выбрать оценку от 1 до 5;
2. написать текст или выбрать «Без текста»;
3. разрешить публикацию либо оставить отзыв только для салона;
4. подтвердить отправку.

Публичным отзыв становится только после согласия клиента и модерации сотрудником.

### «⏳ Лист ожидания»

«➕ Добавить запрос» последовательно спрашивает услугу, диапазон дат и удобное время: любое,
утро, день или вечер. Собственные запросы показаны по страницам. Кнопка «Отменить» рядом с
запросом прекращает ожидание. Когда появляется подходящее окно, клиент получает сервисное
уведомление и может перейти к записи.

### «🔔 Настройки уведомлений»

- сервисные уведомления о действующей записи всегда включены;
- рекламные сообщения можно включить или выключить;
- напоминания о повторной записи можно выключить отдельно;
- повторные напоминания требуют действующего рекламного согласия.

### «🔐 Приватность» и удаление данных

Раздел открывает политику конфиденциальности и оферту. `/delete_my_data` создаёт запрос, который
нужно отдельно подтвердить. Сотрудник проверяет запрос перед обезличиванием. Финансовая и
сервисная история может сохраняться в обезличенном виде, если это требуется для учёта.

## 4. Панель мастера

Мастер открывает `/master` либо `/start` → рабочий режим. Мастер видит только собственные данные.

| Кнопка | Назначение |
|---|---|
| «📅 Мои записи» | Ближайшие и недавно завершившиеся записи мастера, по 8 на странице |
| «🕒 Моё расписание» | Текущий недельный шаблон, исключения, пауза и создание свободного окна |
| «🖼 Моё портфолио» | Черновики, публикация и архив только собственных работ |
| «💳 Предоплаты» | Ручные предоплаты по собственным записям, ожидающие проверки |
| «🛟 Поддержка» | Техническая поддержка владельца CRM, не клиентские контакты салона |

### Действия с записью мастера

- «✅ Завершить» разрешено с момента начала записи: используйте его, если процедура закончилась
  раньше запланированного окна;
- «🚫 Неявка» отмечает, что клиент не пришёл;
- «❌ Отменить» доступно для будущей активной записи;
- каждое изменение требует отдельного подтверждения.

### «🕒 Моё расписание»

- «➕ Открыть свободное окно» запускает календарь и выбор времени;
- «Приостановить на 1 день» и «На 7 дней» временно исключают мастера из онлайн-записи;
- «Возобновить онлайн-запись» снимает паузу;
- создаваемое окно означает свободное время мастера и не привязывается к конкретной услуге.

### «💳 Предоплаты»

Мастер видит только платежи своих клиентов. «Подтвердить предоплату» следует нажимать только
после фактического поступления денег. После подтверждения зарезервированная запись активируется.

### «🖼 Моё портфолио»

- «➕ Добавить работу» загружает фотографии, название и описание;
- «📢 Опубликовать» показывает работу клиентам;
- «💾 Сохранить черновик» оставляет работу невидимой;
- «📦 Архивировать» снимает работу с публичного показа;
- список работ разбит на страницы.

Владелец может управлять портфолио любого мастера. Обычный мастер не получает доступ к работам
коллег через рабочую панель.

## 5. Административная панель

Состав `/admin` определяется ролью. Если кнопки нет, у текущего сотрудника нет необходимого права
или функция отключена.

### «📅 Сегодня» и «🗓 Ближайшие записи»

Показывают календарную повестку по дням. Каждая строка содержит время, мастера, клиента и услугу.
Списки разбиты на страницы. Нажатие открывает полную карточку с контактами, ценой, рабочим местом,
предоплатой и статусом.

| Кнопка карточки | Назначение |
|---|---|
| «💬 Написать клиенту» | Открывает публичный Telegram username, если клиент его установил |
| «✅ Подтвердить визит» | Отмечает подтверждение активной записи |
| «Завершить визит» | Завершает активный визит с момента начала окна, в том числе досрочно |
| «🚫 Отметить неявку» | Отмечает неявку только после окончания окна |
| «🔄 Перенести» | Выбирает другое совместимое открытое окно |
| «❌ Отменить» | Предлагает освободить исходное окно или оставить его закрытым |
| «🖼 Референсы» | Показывает клиентские фотографии |
| «🗑 Удалить референсы» | Удаляет фотографии после отдельного подтверждения |

Отсутствие публичного username не ломает карточку: телефон и Telegram ID остаются текстом, а
небезопасная кнопка связи просто не показывается.

В служебном напоминании «Ближайшая запись» кнопка «📋 Перейти к записи» открывает эту же
административную карточку. Доступ повторно проверяется по актуальной роли сотрудника.

### «➕ Добавить окно»

1. В салоне с несколькими специалистами выбрать мастера.
2. Выбрать дату календарём, включая «Сегодня».
3. Выбрать время или ввести его вручную.
4. Использовать длительность по умолчанию либо ввести другую.
5. Добавить внутренний комментарий или пропустить.
6. Проверить данные и нажать «✅ Создать окно».

После создания можно добавить ещё время на ту же дату, перейти к другой дате или завершить.
Пересечения окон одного мастера и несовместимые интервалы блокируются сервером.

### «🕒 Открытые окна»

Список содержит ID, дату, время, мастера и статус. Архив скрыт по умолчанию.

- «⏸ Закрыть» запрещает новые записи в окно;
- «▶️ Открыть снова» возвращает закрытое свободное окно;
- «🗄 Показать архив» и «🙈 Скрыть архив» переключают отображение;
- «🗑 Удалить» предлагает обычное безопасное удаление;
- «🔥 Удалить вместе с записью» — безвозвратное действие с отдельным подтверждением.

Принудительное удаление нужно использовать только для тестовых или ошибочных данных. Для
реальной истории безопаснее закрывать и архивировать.

### «🛠 Услуги»

Список активных услуг разбит на страницы, архив скрыт по умолчанию.

#### Добавление услуги

Бот последовательно спрашивает:

1. название;
2. описание или пропуск;
3. цену;
4. минимальную длительность;
5. максимальную длительность;
6. фиксированную предоплату.

Цена `0` означает «договорная». Предоплата не может быть больше цены; при переходе существующей
услуги на договорную цену фиксированная предоплата сбрасывается до нуля.

#### Карточка услуги

| Кнопка | Назначение |
|---|---|
| «📷 Фотография» | Добавить, заменить или удалить фото |
| «➕ Допуслуги» | Управлять дополнениями к основной услуге |
| «✏️ Название» | Изменить название |
| «📝 Описание» | Изменить описание |
| «💳 Предоплата» | Изменить фиксированную сумму |
| «💵 Цена» | Изменить стоимость; `0` — договорная |
| «⏱ Длительность» | Изменить минимальное и максимальное время |
| «⏸ Скрыть» / «▶️ Активировать» | Убрать услугу из клиентского каталога или вернуть её |
| «🗑 Удалить» | Обычное или принудительное удаление после подтверждения |

Допуслуга имеет собственные название, описание, цену, длительность, фото и статус. Архивирование
предпочтительнее физического удаления данных, которые уже использовались в записях.

### «👥 Клиенты»

Клиенты показаны по страницам. «🔎 Поиск» ищет по доступным данным, «🏷 Все теги» управляет CRM-
метками. Карточка клиента содержит историю посещений, доступный контакт и служебную информацию.

| Кнопка | Назначение |
|---|---|
| «Открыть профиль» | Открывает публичный Telegram username, если он есть |
| «📚 История» | Постранично показывает записи, локальное время, мастера, стоимость, предоплату и возвраты |
| «🏷 Теги» | Назначает или снимает CRM-теги |
| «📝 Заметки» | Добавляет внутренние заметки, не видимые клиенту |
| «✉️ Написать» | Отправляет клиенту сервисное сообщение через бота |
| «➕ Создать запись» | Сначала просит ID услуги, затем показывает подходящие окна и просит ID окна |
| «⛔ Запретить самостоятельную запись» | Блокирует новые самостоятельные бронирования клиента |
| «✅ Разрешить самостоятельную запись» | Снимает блокировку |

Создание записи сверх клиентского лимита требует отдельного права и причины для журнала аудита.
История показывает только суммы, проведённые через встроенный контур предоплаты. Наличные и
окончательный расчёт вне бота автоматически не учитываются.

### «🖼 Портфолио»

Главное меню содержит:

- «➕ Добавить работу»;
- «📋 Все работы»;
- «🏷 Категории и теги»;
- «👁 Опубликованные»;
- «🗄 Архив»;
- «⚙️ Режим показа».

При добавлении владелец выбирает мастера, загружает фотографии, вводит название, описание,
связанную услугу, цену дизайна, порядок и теги. Работу можно опубликовать, сохранить черновиком
или архивировать.

Режимы показа:

- «Встроенное» — работы показываются в Telegram;
- «Внешняя ссылка» — клиент получает настроенную HTTPS-кнопку;
- «Выключено» — клиентская кнопка скрыта, но администрирование остаётся доступным.

### «⏳ Лист ожидания»

«Активные» показывает текущие запросы, «Все» — также завершённые и отменённые. В карточке можно:

- написать клиенту;
- предложить ID открытого окна;
- архивировать запрос;
- вернуться к списку.

### «⭐ Отзывы»

Отзывы разбиты на активные и удалённые. В карточке можно изменить оценку или текст, опубликовать
отзыв при наличии согласия клиента, отклонить, скрыть или удалить. Удалённый отзыв можно
восстановить. «Удалить навсегда» требует отдельного подтверждения.

### «📢 Рассылки»

Раздел содержит черновики, запланированные, выполняющиеся, завершённые и общие результаты.

Создание рассылки:

1. название и текст;
2. необязательная фотография;
3. аудитория: все подписанные, с выполненными визитами, без будущей записи, не посещали 30 дней,
   по тегу или по услуге;
4. кнопка: без кнопки, записаться, портфолио, свободные окна или HTTPS-ссылка;
5. предварительный просмотр;
6. тестовая отправка себе;
7. немедленный запуск или планирование.

Рассылка отправляется только клиентам с действующим маркетинговым согласием. Фоновая очередь
переживает перезапуск контейнера, имеет повторные попытки и позволяет отменить незавершённую
рассылку.

### «🛡 Запросы на удаление»

Жизненный цикл запроса:

1. «Взять в работу»;
2. «Одобрить» либо «Отклонить» с обязательной стандартной причиной;
3. «Выполнить обезличивание»;
4. при безопасно остановленной ошибке — «Безопасно повторить».

Активные сотрудники и bootstrap-владелец защищены от случайного обезличивания. Сначала требуется
отозвать их рабочую роль. Операции записываются в аудит без свободного текста с персональными
данными.

### «👩‍💼 Мастера и сотрудники»

В списке видно роль, активность, привязку Telegram и возможность принимать записи.

- «➕ Добавить сотрудника» создаёт одноразовую ссылку-приглашение;
- приглашение можно создать для владельца, администратора, мастера или менеджера записи в рамках
  прав текущего пользователя;
- ожидающее приглашение можно отозвать;
- в карточке сотрудника меняются имя, специализация, описание, фото и до пяти контактов;
- «🛠 Назначить услуги» определяет, что может выполнять специалист;
- «Принимать записи» публикует специалиста для клиентов;
- «🚫 Отозвать доступ» отключает рабочую роль;
- будущие записи отключённого мастера можно переназначить активному специалисту.

Владельца, который работает сам, достаточно отметить как принимающего записи и назначить ему
услуги. Ручной переключатель solo/salon не нужен: режим формируется по числу активных мастеров.

### «💳 Предоплаты»

Главное меню разделено на:

- «⏳ Действующие» — платежи, требующие действия или ожидающие завершения;
- «✅ История» — завершённые, отклонённые и возвращённые платежи;
- «⚙️ Настройки предоплаты» — доступно только сотруднику с правом изменения конфигурации.

Карточка показывает дату и время записи, клиента, услугу, мастера, сумму, режим и статус.

| Кнопка | Назначение |
|---|---|
| «💬 Написать клиенту» | Начинает безопасную отправку сообщения через бота |
| «✅ Подтвердить получение денег» | Подтверждает ручную оплату после проверки поступления |
| «❌ Отклонить предоплату» | Просит причину и освобождает резерв по правилам платежа |
| «↩️ Оформить возврат остатка» | Создаёт возврат доступного остатка |
| «Настроить инструкцию ручной оплаты» | Сохраняет текст после предварительного просмотра |
| «Настроить таймер оплаты» | Задаёт от 5 до 60 минут на оплату |
| «Режим: без предоплаты» | Новые записи подтверждаются сразу |
| «Режим: вручную» | Клиент получает инструкцию, салон вручную проверяет оплату |
| «Режим: YooKassa» | Использует подключённый платёжный аккаунт и webhook |

Для ручной инструкции разрешены СБП-телефон, безопасная платёжная ссылка и обычный текст. Нельзя
просить CVV/CVC, SMS-код или срок действия карты. Переключение режима требует подтверждения и
влияет только на новые записи.

### «📊 Статистика»

Показывает источники клиентов и воронку: пришли, начали запись, завершили визит, вернулись повторно.
Владелец может создать источник, получить deep-link вида `/start ...` и использовать эту ссылку в
рекламе или QR-коде. В код источника нельзя добавлять имя, телефон или другие персональные данные.

| Кнопка | Где используется |
|---|---|

| «🏷 Название» | Заголовки клиентского и рабочего интерфейса |
| «📝 Описание» | Полное описание профиля бота после синхронизации |

«Адрес и карта» разделены: адрес показывается текстом, карта открывается только по сохранённой
HTTPS-ссылке. Часовой пояс удобнее выбирать по ближайшему городу; ручной формат — IANA, например
`Europe/Moscow`.

#### Рабочие места

Рабочее место — реальный стол, кресло или кабинет. После создания отметьте услуги, которые на нём
можно выполнять. Если одну услугу поддерживают два активных места, одновременно её могут выполнять
два разных мастера. При подтверждении записи бот блокирует распределение на уровне PostgreSQL,
поэтому два одновременных запроса не получают одно место.

Рабочее место можно архивировать и восстановить. Списки мест и назначаемых услуг разбиты на
страницы.

### «⚙️ Настройки»

| Настройка | Объяснение |
|---|---|
| Лимит записей в день | Максимум новых записей одного клиента в календарные сутки |
| Горизонт записи | На сколько дней вперёд клиент может выбирать дату, до 365 дней |
| Отмена не позднее | За сколько часов до визита клиент теряет кнопку самостоятельной отмены |
| Перенос не позднее | За сколько часов до визита клиент теряет кнопку самостоятельного переноса |
| Окно по умолчанию | Стандартная длительность нового свободного окна |
| Интервал между окнами | Минимальный промежуток между окнами мастера |
| Напоминания о записи | Когда клиент получает сервисные напоминания |
| Лимит клиента | Максимум будущих записей в антиспам-периоде |
| Горизонт антиспама | Период, в котором считается лимит будущих записей |
| Учитывать отмены клиента | Включать ли отменённые клиентом записи в защитный лимит |
| Суббота / воскресенье | Разрешить или запретить выбор этих дней |

Для напоминаний есть готовые варианты: за день/3 часа/1 час, за день/2 часа или за 3 часа/1 час.
Свой график принимает от 1 до 5 уникальных значений в минутах. Например `1440,180,60` означает
«за 24 часа, за 3 часа и за 1 час».

### «🛟 Техническая поддержка»

Это связь владельца CRM с разработчиком или оператором продукта. Она настраивается через
`VENDOR_SUPPORT_*` в `.env` и не показывается клиентам салона. Клиентские каналы связи задаются
отдельно в «Настройки бизнеса» → «Источники поддержки».

## 6. Страницы и устаревшие кнопки

Растущие операционные списки показываются небольшими страницами: услуги, окна, записи, клиенты,
отзывы, лист ожидания, платежи, запросы удаления, рассылки, рабочие места, портфолио и рабочие
списки мастера. Стрелки не создают новое сообщение, а обновляют текущую карточку там, где это
поддерживает Telegram.

Если другой сотрудник уже изменил объект, старая кнопка не должна повторно применять действие.
Бот заново проверяет существование, статус, бизнес, роль и доступность объекта и сообщает, что
карточка устарела или действие больше недоступно.

## 7. Ежедневный рабочий порядок

### Перед началом дня

1. Проверить «📅 Сегодня».
2. Проверить действующие предоплаты.
3. Проверить открытые окна всех мастеров.
4. Обработать новые запросы листа ожидания и удаления данных.

### После визита

1. Открыть запись.
2. Нажать «Завершить визит» либо «Неявка».
3. Проверить корректность платежа и возврата.
4. При необходимости модерировать полученный отзыв.

### При изменении каталога

Архивируйте использованную услугу вместо удаления. Принудительное удаление применяйте только
после проверки связанных записей, дополнений, окон и финансовой истории.

## 8. Если кнопка не работает

1. Отправьте `/start` и заново выберите режим.
2. Проверьте, включена ли функция в «🧩 Функции бота».
3. Проверьте роль и активность сотрудника в «👩‍💼 Мастера и сотрудники».
4. Для записи проверьте активную услугу, назначение услуги мастеру, рабочее место и открытое окно.
5. Для ручной оплаты проверьте инструкцию, переключатели «Предоплата» и «Ручная оплата».
6. Посмотрите состояние контейнеров: `docker compose ps`.
7. Проверьте healthcheck: `docker compose run --rm bot python -m app.healthcheck`.
8. Посмотрите последние логи: `docker compose logs --tail 100 bot`.

Не публикуйте `.env`, токены, пароли, чеки и персональные данные клиента в общем чате или issue.
