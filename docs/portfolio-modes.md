# Режимы портфолио v0.3.0

## Режимы

- `internal`: клиентская кнопка открывает существующее встроенное портфолио.
- `external_link`: кнопка является URL-кнопкой с `external_portfolio_button_text`.
- `disabled`: кнопка полностью отсутствует, а старые callback/deep links возвращают недоступное состояние.

Переключение режима не изменяет и не удаляет portfolio items, media или tags.

## Внешний адрес

Разрешён только абсолютный `https` URL с host. `javascript:`, `http:`, Telegram callback payload и пустой адрес отклоняются. Режим `external_link` нельзя активировать без валидного URL и непустого текста кнопки.

## Совместимость

Миграция преобразует `portfolio_enabled=true` в `internal`, `false` в `disabled`. Старое поле временно сохраняется, но новое UI-решение принимается по `portfolio_mode`. `PortfolioService.get_published` и list/deep-link пути обязаны одинаково проверять активный режим.

## Административный preview

Перед сохранением администратор видит текущий режим и точный вид клиентской кнопки. Изменение режима, URL и текста фиксируется AuditLog без удаления внутреннего контента.
