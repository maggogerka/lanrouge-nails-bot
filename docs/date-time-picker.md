# Выбор даты и времени v0.3.0

## Назначение

Компоненты date/time picker отвечают только за представление и разбор компактных callback-команд. Они не заменяют серверные проверки `AvailabilityService`.

## Календарная страница

- Начало первой страницы — локальная сегодняшняя дата бизнеса.
- Размер по умолчанию — 31 последовательный календарный день, но не дальше `today + booking_horizon_days` включительно.
- Переход месяца и года выполняется арифметикой `datetime.date` и `timedelta`.
- Подпись: `DD.MM Дд`, например `01.08 Сб`.
- Раскладка: три даты в строке.
- Callback выбранной даты содержит ISO `YYYY-MM-DD`, а не ordinal и не отображаемый текст.
- Запрещённый выходной отображается с `🚫` и использует noop callback.
- Навигация: предыдущая страница, сегодня, следующая страница, назад и отмена.

Callback-префикс и команды должны укладываться в лимит Telegram 64 байта. Разбор callback не является авторизацией или валидацией: handler повторно проверяет текущую локальную дату, актуальный горизонт и настройки выходных.

## Выбор времени

- 24 кнопки от `00:00` до `23:00`, четыре в строке.
- `24:00` не создаётся.
- Дополнительные действия: ручной ввод, другая дата, отмена.
- Шаг кнопок задаётся `availability_time_step_minutes`; для v0.3.0 поддерживаемое начальное значение — 60 минут. Если шаг не делит сутки без остатка, настройка отклоняется.

Ручной ввод принимает `H:MM` и `HH:MM`, затем нормализует через объект `time` в `HH:MM`. Часы допустимы только `0..23`, минуты — `0..59`.

## Повторная проверка

Перед экраном подтверждения и непосредственно перед insert сервис повторно проверяет:

1. начало строго в будущем;
2. календарный горизонт;
3. правила субботы и воскресенья;
4. положительную длительность;
5. дневной лимит;
6. пересечения и minimum gap;
7. локальный timezone из `BusinessSettings` с сохранением UTC.

Устаревший callback возвращает понятное сообщение и новую актуальную клавиатуру. Частичное окно в БД не создаётся.

## FSM создания окна

`date → time → duration → comment → confirmation`. Из подтверждения можно изменить каждое поле. После commit доступны действия: добавить время на сохранённую дату, выбрать другую дату, открыть список окон или завершить.
