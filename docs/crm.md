# CRM-карточки клиентов

Раздел `/admin` → «👥 Клиенты» поддерживает поиск по имени, username, телефону и
внутреннему ID, стабильную пагинацию и карточку клиента. Карточка показывает безопасные
операционные данные, историю визитов, CRM-теги и внутренние заметки.

Заметки доступны только администраторам, ограничены 2000 символами, не выводятся клиенту
и не копируются целиком в AuditLog. Не размещайте в них медицинские, банковские и другие
чувствительные данные. Архивирование используется вместо потери истории.

Администратор может запретить самостоятельную запись, отправить личное сообщение или
создать запись вручную. Полномочия всегда сверяются с `ADMIN_TELEGRAM_IDS`; поле роли в
таблице пользователей не является источником авторизации.

Код: `app/handlers/admin/crm.py`, `app/services/crm_service.py`,
`app/repositories/crm_repository.py`.
