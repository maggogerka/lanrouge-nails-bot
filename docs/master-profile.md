# Информация о мастере v0.3.0

## MasterProfile

Типизированная singleton-сущность содержит отображаемое имя, bio, необязательный Telegram photo file ID, адрес, map URL, Telegram URL, статус публикации и timestamps редактора. `master_profile_enabled` в BusinessSettings является глобальным feature flag.

Клиент видит профиль только при одновременных `enabled=true` и `published=true`. Фотография необязательна. Неполный черновик сохранять можно, публиковать без имени нельзя.

## MasterPublicLink

Ссылка содержит подпись, абсолютный HTTPS URL, `sort_order`, `is_active` и timestamps. Публичная выдача сортируется по `sort_order, id`; неактивные строки не показываются. Произвольные схемы и URL без host запрещены.

## Права и аудит

Создание, редактирование, публикация профиля и управление ссылками доступны только актуальному администратору и повторно проверяются service layer. AuditLog содержит IDs, изменённые имена полей и безопасные значения, но не photo file ID полностью.

## Начальное заполнение

Миграция может создать черновой профиль из существующих `business_name`, `business_address`, `business_map_url` и `master_telegram_url`. Она не публикует автоматически данные, которые раньше не имели отдельного публичного статуса.
